# Jobnet interactive page

The bilingual page is published at [ristohinno.com/jobnet](https://ristohinno.com/jobnet/). Use the EN / ET switch to change language. The Estonian page has translated chart labels under `charts/et/`; the English page uses the charts directly under `charts/`.

Plotly.js is loaded from the public Plotly CDN. The analysis uses the original Frey–Osborne scenario and links to the source article.
